# ❤️ Heart Disease Prediction Web Application

## 📌 Overview

This is a Machine Learning web application that predicts the likelihood of heart disease based on patient health parameters using a Random Forest model integrated with a Flask web application.

## 🚀 Features

- Predicts heart disease risk
- Machine Learning Pipeline
- Random Forest Classifier
- Flask Backend
- HTML & CSS Frontend
- Confidence Score Display

## 🛠 Technologies Used

- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML
- CSS
- Joblib

## 📊 Model Performance

- Model: Random Forest Classifier
- Accuracy: ~85%

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/Thanmayeenadimpalli/HeartDiseasePrediction.git
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
python app.py
```

4. Open your browser:

```
http://127.0.0.1:5000
```
